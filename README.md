# Nijat Akbarov · Portfolio

Live: **[nijat-akbarov.vercel.app](https://nijat-akbarov.vercel.app)**

A one-page portfolio for product roles. It covers two products I build:

- **[Testavi](https://testavi.com)**, co-founder and product lead. AI agents that test web app user flows from plain-English steps.
- **[MoveStart](https://movestart.app)**, founder. An AI fitness coach on the App Store and Google Play.

It also lists my experience, from QA tester to CPO, and links to my CV.

## How it's built

Plain HTML and CSS in a single `index.html`, with no framework and no build step. Images are in `assets/`. It deploys to Vercel on every push to `main`.
